# 宏观报告工作台

本地 Web 工作台：分类浏览、全文搜索、内嵌阅读各家机构的宏观/大宗商品研报，并自动关联 AI 精读总结页。

**栏目结构：一级节 = 机构，二级节 = 机构-品种。** 例如 `reports/Goldman Sachs/铜/` 下的报告在侧栏显示为 Goldman Sachs → 铜。

## 启动

双击 **启动宏观报告工作台.bat** 即可（自动打开浏览器，地址 `http://127.0.0.1:8766`）。
关闭黑窗口即停止服务。

命令行方式：

```bash
cd 宏观报告工作台
"C:/Users/连瑞康/.workbuddy/binaries/python/envs/default/Scripts/python.exe" server.py
```

依赖：仅 Python 标准库即可运行；装了 PyMuPDF（当前 venv 已装）才有 PDF 全文搜索，缺失时自动降级为只搜标题/分类。

## 放入报告

把 PDF 放进 `reports/` 下对应 **机构/品种** 文件夹，回到浏览器点「刷新」即可（切回浏览器窗口也会自动刷新）。

```
reports/
├─ Goldman Sachs/
│  ├─ 铜 · 商品策略 · 能源 · 天然气 · 铁矿石
├─ J.P. Morgan/铜
├─ Morgan Stanley/煤炭 · 钨
├─ 瑞银证券/油气化工
├─ Macquarie/能源
├─ Societe Generale/商品策略
├─ RBC Capital Markets/商品
├─ HSBC/金属
└─ Bernstein/金属矿业
```

- **文件名建议带日期**：`2026-11-14 标题.pdf`、`20261114_标题.pdf` 均可识别；识别不出就用文件修改时间。
- 新机构直接建文件夹即可，新品种在机构下建子文件夹，侧栏树自动出现；没有子文件夹的报告直挂机构一级节下。

## AI 归档 + 精读总结（与 AI 协作约定）

把 PDF 交给 AI 时说一句「**归档到宏观报告工作台并生成总结**」，AI 会：

1. 把 PDF 按机构/品种放入 `reports/` 对应文件夹，命名 `YYYY-MM-DD 标题.pdf`；
2. 用「研报精读总结」流程生成自包含 HTML 总结页（图表从原文裁剪、base64 内嵌）；
3. 总结页存到 `summaries/` 下 **与 PDF 同名镜像** 的路径：

```
reports/Goldman Sachs/铜/2026-11-12 Base Metals Comment.pdf
              ↕ 同名镜像（自动发现，无需登记）
summaries/Goldman Sachs/铜/2026-11-12 Base Metals Comment.html
```

工作台里该报告会自动出现「总结」标签和「AI 总结」入口。

**只放总结、不归档原文也可以**：把总结页单独放进 `summaries/<机构>/<品种>/`（命名同样带日期），工作台会显示为「仅总结 · 无PDF」条目，点「总结」直接阅读。

## 功能

- **分类树**：左侧机构 → 品种，节点带数量
- **搜索**：搜标题、品种、PDF 全文（PyMuPDF 提取、`.index/` 缓存按 mtime 失效）、AI 总结页文本；命中带片段高亮和来源标记
- **日期筛选**：今天 / 近7天 / 近30天 / 自定义起止
- **阅读**：浏览器内嵌 PDF；有总结的报告可在「原文 PDF ↔ AI 总结」间切换
- **已读标记**：读过的标题变灰（存浏览器 localStorage）
- **排序**：日期新→旧 / 旧→新 / 标题
- **今日更新横幅**：只显示当天新放入/更新的报告

## 常用路径与修改

| 事项 | 位置 |
|---|---|
| 改端口 | `server.py` 顶部 `PORT = 8766` |
| 改机构顺序 | `server.py` 顶部 `ORGS` |
| 清空全文缓存 | 删除 `.index/` 文件夹（会自动重建） |

> `.index/` 是全文搜索缓存目录，可随时删除，不影响报告文件。
